# **Project fraud detection** #

# *This section describes the differents folders and files of this project and their purpose* #

- **`Data/`**: contains the dataset used in this project 
  - **`raw/`**: stores the original, unmodified data set 
  - **`processed/`**: stores the data set after cleaning, preprocessing and transformation
- **`models/`**: stores the trained models for fraud detection
- **`notebooks/`**: contains the jupyter notebooks used for data exploration, experimentation and visualization. 
- **`source/`**: contains reusable Python scripts for data processing, feature engineering and model training. 
- **`visualization/`**: stores graphs, vizualisations and analysis results.
- **`requirements.txt/`**: contains the libraries required to run this project
